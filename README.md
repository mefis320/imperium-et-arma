# Imperium et Arma

Образовательный сайт об истории оружия и военной тактики. Восемь статических страниц, HTML, CSS, JavaScript и локальная копия Bootstrap 5.3.0 / Bootstrap Icons 1.10.0.

## Запуск

Откройте index.html или запустите из папки сайта:

```sh
python -m http.server 8000
```

Затем откройте http://localhost:8000. Сборка и серверная база данных не нужны.

## Публикация

Сайт можно разместить на GitHub Pages: Settings → Pages → Deploy from a branch → main → / (root). Все пути относительные и поддерживают размещение в подпапке репозитория.

## Интерфейс

- Адаптивная сетка для телефонов, планшетов и мониторов.
- Мобильное меню с управлением клавиатурой, закрытием по Escape и возвратом фокуса.
- Галереи: кнопки, стрелки клавиатуры и горизонтальные свайпы. Автоперелистывание отключено для удобного чтения подписей.
- Ссылки на термины открывают нужный раздел глоссария.
- Изображения WebP с заданными размерами и отложенной загрузкой.
- Локальные стили, скрипты и шрифты: CDN для работы сайта не требуется.
